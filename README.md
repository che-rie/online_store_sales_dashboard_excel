Online Store Sales Dashboard (Excel Project)

Project Overview

This project analyzes an online store’s sales data using Microsoft Excel. The goal is to uncover insights into revenue, profit, customer behavior, and product performance.

Tools Used
•	Microsoft Excel
•	Pivot Tables
•	Excel Charts
•	Slicers
•	KPI Metrics

Key Insights
•	Lagos generated the highest profit.
•	Instagram is the most effective marketing channel.
•	Chairs, printers, and laptops are top-selling products.
•	Online payments are the most preferred method.
•	Sales are evenly distributed between male and female customers.

Recommendations
•	Increase marketing efforts in Lagos
•	Invest more in Instagram advertising
•	Focus on high-performing products
•	Improve low-performing product sales (e.g., phones)
•	Enhance referral marketing strategy
